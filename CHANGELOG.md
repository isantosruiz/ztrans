# Changelog

All notable changes to this project will be documented in this file.

The format follows the spirit of Keep a Changelog, and this project uses semantic
versioning where possible.

## [0.1.0] - 2026-03-03

### Added

- Initial public release of symbolic unilateral Z-transform utilities.
- Forward transforms for expressions, strings, callables, and finite sequences.
- Rational inverse Z-transform support by residue summation.
- Formal `ZTransform` and `InverseZTransform` placeholders.
- Correspondence and initial-condition helpers.
- pytest-based test suite.
