# Review Readiness

This page tracks repository items commonly expected for pyOpenSci and software
journal review.

## Present

- OSI-approved MIT license.
- README with installation, scope, examples, testing, contribution, citation, and
  license information.
- pytest test suite.
- GitHub Actions workflow for tests.
- Contributor guide.
- Code of Conduct.
- Citation metadata.
- Zenodo metadata.
- Documentation source files.
- Packaging metadata in `pyproject.toml`.

## To Complete Before Journal Publication

- Publish a tagged release.
- Archive the release with Zenodo or another preservation service.
- Add the generated DOI to `CITATION.cff`, README, and manuscript metadata.
- Confirm whether the package should be published to PyPI before review.
- Add any required funding and competing interest statements.
- Disclose any material use of generative AI tools in the review submission.
